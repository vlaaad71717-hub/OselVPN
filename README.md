# 🛡️ OselVPN

**OselVPN** — это легковесный VPN-клиент для Windows на базе ядра [Xray-core](https://github.com/XTLS/Xray-core).
Поддерживает протокол **VLESS** с транспортами TCP / WebSocket / gRPC и защитой **TLS / REALITY**.
Ядро Xray вшивается прямо в исполняемый файл как COFF-объект и распаковывается в `%APPDATA%\OselVPN` при первом запуске.

> Цель проекта — простой, автономный и не требующий установки VPN-клиент «в один клик»: вставил VLESS-ссылку → нажал «Подключить» → браузер уже через VPN.

---

## ✨ Возможности

- 🔌 **Поддержка VLESS** (TCP / WS / gRPC) с TLS и REALITY
- 🧩 **Вшитое ядро Xray** — отдельный файл `xray.exe` не нужен
- 🌐 **Автоматический системный прокси** (WinINET): браузеры начинают ходить через VPN сразу после подключения
- 🪟 **Нативный Win32 GUI** без Electron и тяжёлых зависимостей (≈34 МБ бинарник, всё статически слинковано)
- 📋 **Живой лог Xray** в окне приложения — сразу видно причину ошибки
- 💾 **Сохранение последней ссылки** между запусками
- ⚡ **Минимальные зависимости**: ядро Windows 10/11 x64, ничего больше

## 🔧 Сборка

### Требования

- Linux/macOS/WSL с установленным **Python 3** и **zip**
- [**Zig 0.13.0**](https://ziglang.org/download/0.13.0/zig-linux-x86_64-0.13.0.tar.xz) — используется как кросс-компилятор (замена MinGW)
- Скачанный `xray.exe` (Windows x64) из официальных релизов Xray-core

### Шаги

```bash
# 1. Скачай Zig и распакуй, например в ~/tools/zig
wget https://ziglang.org/download/0.13.0/zig-linux-x86_64-0.13.0.tar.xz
tar xf zig-linux-x86_64-0.13.0.tar.xz
export ZIG=$PWD/zig-linux-x86_64-0.13.0/zig

# 2. Скачай xray.exe (Xray-core XTLS/Xray-core releases) и положи рядом с исходниками
#    https://github.com/XTLS/Xray-core/releases/latest
#    Имя файла должно быть:  xray.exe

# 3. Запусти сборку
./build.sh
```

### Что делает `build.sh`

1. Запускает `tools/gen_payload_coff.py` — оборачивает `xray.exe` в COFF-объект `xray_payload.o` с символами `_xray_payload_start` / `_xray_payload_end`.
2. Кросс-компилирует `OselVPN.cpp` через Zig в статический,stripped GUI-бинарник для Windows x64.
3. На выходе: **OselVPN.exe** (~34 МБ) — полностью автономный клиент.

### Ручная сборка (без build.sh)

```bash
# 1. Упаковать xray.exe в COFF-объект
python3 tools/gen_payload_coff.py xray.exe xray_payload.o

# 2. Скомпилировать клиент
$ZIG c++ -target x86_64-windows-gnu -O2 -static -s \
    -Wl,--subsystem,windows \
    OselVPN.cpp xray_payload.o \
    -lws2_32 -lwininet -ladvapi32 -luser32 -lgdi32 \
    -o OselVPN.exe
```

## 🚀 Использование

1. Запусти **OselVPN.exe**.
2. Вставь в поле VLESS-ссылку, например:

   ```
   vless://11111111-2222-3333-4444-555555555555@example.com:443?encryption=none&security=reality&sni=www.microsoft.com&fp=chrome&pbk=PUBLICKEY&sid=ab12&type=tcp&flow=xtls-rprx-vision#MyServer
   ```

3. Нажми **«Подключить»**.
4. Через 1–2 секунды статус сменится на **«Подключено»** — теперь браузеры ходят через VPN.
5. Чтобы отключиться — нажми **«Отключить»** (системный прокси автоматически снимется).

### Локальные порты

| Порт | Протокол | Назначение |
|------|----------|------------|
| 10808 | SOCKS5 | Для приложений с ручной настройкой прокси |
| 10809 | HTTP   | Системный прокси (включается автоматически) |

```
 │  ┌─────────────────────┐ │                    │ слушает
 │  │  Журнал Xray        │ │◀─────── лог ───────┤ SOCKS5 :10808
 │  └─────────────────────┘ │                    │ HTTP   :10809
 │  ┌─────────────────────┐ │                    │
 │  │  Статус: Подключено │ │                    ▼
 │  └─────────────────────┘ │          системный прокси WinINET
 └──────────────────────────┘                (ProxyServer=127.0.0.1:10809)
```

### Ключевые компоненты

- **`vless.h`** — чистый C++ (STL), без зависимости от Windows: парсит `vless://...?query#name` и собирает `config.json` для Xray-core. Работает и на Linux (используется в тестах).
- **`OselVPN.cpp`** — GUI на чистом WinAPI. Создаёт окно, поле ввода, кнопки, статус, журнал. Запускает `xray.exe` как подпроцесс с пайпом на stdout/stderr, читает лог в отдельном потоке, проверяет что локальный SOCKS-порт открылся и тогда включает системный прокси.
- **`tools/gen_payload_coff.py`** — генерирует валидный PE/COFF x86-64 объект, в котором бинарник `xray.exe` лежит в секции `.rdata` с двумя символами: начало и конец блоба. Zig/lld линкует это как обычный `.o`-файл.

## ⚠️ Известные ограничения

- Системный прокси работает только для приложений, которые его читают (Chrome, Edge, Firefox, Telegram — да; многие CLI-утилиты — нет). Для них используй `socks5://127.0.0.1:10808` вручную.
- **TUN-режим** (прозрачный VPN для всего трафика) пока не реализован — нужен [Wintun](https://www.wintun.net/) драйвер. Планируется.
- Антивирусы иногда ругаются на статически слинкованный exe — это ложное срабатывание. Добавь папку `%APPDATA%\OselVPN` в исключения.
- Работает только на **Windows 10/11 x64** (зависимость от UCRT).
